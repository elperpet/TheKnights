THE KNIGHTS - SCIENCE COMMUNICATION E-MAGAZINE (CAT)
Rongo University | Group 17 | Issue 1

HOW TO OPEN
  Double-click index.html. It opens in any web browser (Chrome, Edge, Firefox,
  Safari) with no internet and no installation. Works straight from the CD.

NAVIGATE
  Prev / Next buttons, the left and right arrow keys, or swipe on a phone.
  The Contents link (top right) jumps to any story.

FOLDER LAYOUT
  index.html     the magazine (members page, cover, contents, 21 stories, back page)
  stories/       each story as its own stand-alone web page
  images/        all story photos
  css/style.css  design
  js/magazine.js page-turning and navigation
  README.txt     this file

BLOG LINK
  Open index.html in Notepad, press Ctrl+F, search YOUR-BLOG-LINK-HERE and
  replace it with the real blog address (it appears twice, on the last page).
